# Reviewer 1, Major Comment 1 — Reference Standard and MBF

**Working note — 21 September 2026.** This note records the agreed interpretation of Antti Saraste’s responses and the resulting revision plan. It is not manuscript text and does not change the analysis code. The numerical pathway table below is conditional on Antti confirming that the 8 and 15 patients are the complete FFR subgroup.

## Core issue

Reviewer 1 correctly noted that angiographic stenosis and FFR do not describe exactly the same biological target. Quantitative coronary angiography (QCA) describes the anatomical severity of a coronary narrowing, whereas FFR assesses whether a lesion is functionally flow-limiting. Neither pathway alone is identical to a direct, uniform myocardial-ischemia reference standard. The study endpoint must therefore be described as **patient-level significant/obstructive CAD defined by invasive ICA/QCA, with FFR adjudication when available**, rather than as uniformly proven myocardial ischemia.

## Reference-label rule supplied by Antti

Antti’s accepted Methods edits establish the intended hierarchy:

1. Intermediate stenoses (30–70%) were evaluated with FFR when technically feasible.
2. When FFR was available, FFR <0.80 indicated significant disease and FFR ≥0.80 indicated non-significant disease, irrespective of the angiographic narrowing degree.
3. When FFR was unavailable, QCA stenosis ≥50% indicated significant disease.
4. A patient with at least one vessel meeting the applicable significant-disease rule was classified as having significant/obstructive CAD.

The endpoint wording should later use **significant CAD** or **obstructive CAD**, not “ischemic CAD.”

## Stress-MBF threshold: what it means and how it should be presented

The current submitted Methods state that polar maps visualise stress myocardial blood flow (MBF), that values below 2.3 mL/g/min indicate ischemia, and that the images were labelled using ICA as reference. This sequence is ambiguous because it can appear that the 2.3 mL/g/min threshold created the binary labels.

The intended distinction is:

| Item | Role in this study |
|---|---|
| PET stress-MBF polar map | Image input seen by the model; it represents the spatial distribution of myocardial blood flow. |
| Stress MBF <2.3 mL/g/min | A clinical PET-perfusion interpretation threshold, to be supported by the cited literature (e.g., Danad et al.). It was not the rule used to create the binary study labels. |
| ICA/QCA and FFR | The invasive reference system used to assign binary significant-CAD/non-significant-CAD labels. |

The revised manuscript should make the separation in four locations:

1. **Reference-standard / label-assignment Methods paragraph.** Give the ICA/QCA–FFR hierarchy, the patient-level rule, and the confirmed pathway counts. State unambiguously that this system assigned the binary labels.
2. **PET acquisition and polar-map Methods paragraph.** Retain the explanation that the polar maps visualise stress MBF. Add that the 2.3 mL/g/min threshold was not used to assign labels, train models, select models, or evaluate outcomes; it is included only to explain the clinical interpretation of quantitative PET perfusion.
3. **Figure caption and terminology.** Replace “ischemic case” and “non-ischemic case,” where these refer to invasive labels, with “patient classified as significant CAD” and “patient classified as non-significant CAD according to the ICA/FFR reference standard.”
4. **Discussion and conclusion.** Acknowledge that the primary endpoint is invasive-reference-defined significant/obstructive CAD, not a uniformly direct functional reference standard for myocardial ischemia.
